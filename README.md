# Fashion Fits

AI size recommendations for second-hand and vintage clothing.

Fashion Fits reads a photo of a clothing tag (brand, size, country and fabric), finds the brand's published sizing information, and gives each item a fit percentage for the buyer, like "92% match for you".

Built for **Ignite Their Future: An AI Innovation Challenge** (Retail sector), hosted by iSOFT Technologies and Macquarie University.
